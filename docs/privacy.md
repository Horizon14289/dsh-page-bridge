# 隐私政策 / Privacy Policy

**DSH Page Bridge**（以下简称"本扩展"）· 生效日期：2026-11-07

## 我们不收集任何数据

本扩展**不收集、不存储、不传输**任何个人数据到任何服务器。
没有账号系统，没有分析统计，没有崩溃上报，没有广告。

## 数据流向

当你在页面上点击扩展图标或按下 `Alt+Shift+S` 时：

1. 扩展读取**当前这一个标签页**的可见文本（`document.body.innerText`）；
2. 通过 HTTP 把这段文本发送到**你自己指定的本机地址**（默认 `http://127.0.0.1:8777`）；
3. 接收端是你自己在电脑上运行的程序，数据只存在你本地的 `last-page.json` 文件里。

**数据不会离开你的电脑。**

## 权限说明

| 权限 | 用途 |
|---|---|
| `activeTab` | 只在你点击图标或按快捷键的那一刻，获得当前标签页的读取权；平时无法读取任何页面 |
| `scripting` | 注入一小段脚本读取页面可见文本 |
| `storage` | 在你本地记住接收端地址和上一次发送结果 |
| `host_permissions: http://127.0.0.1/*`、`http://localhost/*` | 仅允许把数据发到本机回环地址 |

本扩展**没有**申请 `tabs`、`<all_urls>`、`webRequest` 等宽泛权限，也不加载任何远程代码。

## 内置于浏览器的页面

`edge://`、`chrome://`、扩展商店等浏览器内置页禁止扩展读取，本扩展也无法访问。

## 第三方

本扩展不包含任何第三方 SDK、跟踪脚本或远程配置。

## 变更

若本政策有变更，会更新本文件并在版本说明中注明。
